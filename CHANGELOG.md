## [0.1.0] - 2026-07-26

### Added
- Cryptographic hashing — `sha256`, `sha1`, `sha512`, `md5`
- HMAC — `hmac-sha256`, `hmac-sha1`, `hmac-sha512`, `hmac-md5`
- OpenSSL-backed C FFI shared library built via `make`
- CI workflow for automated testing
